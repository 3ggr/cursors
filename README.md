## Contents (this is a STATIC link cursor)
- `.cur` : Static cursor
- `.ani` : Animated cursor

## How to install
1. Download all cursor files.**(recommend C:\Windows\Cursors)**
3. Right-click → **Personalize** → **Themes** → **Mouse pointers**.
4. In the "Pointers" tab, select each scheme item and browse to replace with the corresponding `.cur` / `.ani` file.
   <img width="314" height="247" alt="image" src="https://github.com/user-attachments/assets/230d6270-4054-43f6-a5cf-d54e84d73174" />
   (here should replace **"link"** )
6. Save as a new cursor scheme.

## Notes
- Only tested on Windows 10 / Windows 11.
- Do not modify system cursor files directly.
